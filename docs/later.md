8. ~~**Registered devices**~~ **DONE (11 Oct 2026).** Browsers cannot read a MAC address, so each approved device holds a secret the server issued (only its hash is kept). The owner or IT makes a one-time code (about 10 minutes, one use, 8 characters) with the device's name; typing it on the device registers it. Revoking signs out everyone on that device at once. You cannot revoke the device you are using. Sign-ins are tied to the device they were made on. The very first device is registered with `npm run admin -- device-code --name "Office laptop"` on the server computer. `REQUIRE_DEVICE=0` switches the check off (local try-outs). Devices and codes stay on the shop server and are never sent online. Limits to know: a stolen sign-in token used from another browser is not caught by the device check once signed in (it is the same risk as any session); the IT page has no Devices screen yet (the owner page does); codes are guarded by a rate limit of 10 tries a minute per address. **Added 17 Oct 2026:** IT has its own small page (`/it.html`: devices and a system summary; the full IT command centre is still to come), **Re-register** for a browser that lost its secret, and the last device can never be revoked.
